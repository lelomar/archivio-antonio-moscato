# Contribuire all'archivio Antonio Moscato

Grazie per volerci dare una mano. I modi più utili:

1. **Hai uno dei documenti mancanti?** Cercalo sulla [lavagna della caccia ai documenti](https://github.com/users/lelomar/projects/2) e allega il file nella sua scheda, oppure apri una segnalazione con il modulo «Ho ritrovato un documento».
2. **Hai un ricordo di Antonio Moscato?** Raccontalo nelle [Discussions](https://github.com/lelomar/archivio-antonio-moscato/discussions).
3. **Hai trovato un errore?** Usa il modulo «Segnala un errore» nelle [issue](https://github.com/lelomar/archivio-antonio-moscato/issues/new/choose).
4. **Vuoi migliorare il codice?** Leggi [Modificare i contenuti](https://github.com/lelomar/archivio-antonio-moscato/wiki/Modificare-i-contenuti) e [Ricostruire da zero](https://github.com/lelomar/archivio-antonio-moscato/wiki/Ricostruire-da-zero) nel wiki, poi proponi una *pull request*. Modifica i programmi in `sviluppo/` o i file in `assets/`, non l'HTML generato.

Principi: nessuna dipendenza esterna, nessun tracciamento, link relativi, funzionamento offline, **crediti intatti** (vedi [CREDITI.md](CREDITI.md)).

Aggiungi il tuo nome nella sezione «Contributi successivi» di `CREDITI.md`.
